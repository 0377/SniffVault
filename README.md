# 嗅影库（SniffVault）

开源、可自编译的**个人离线视频库**：在应用内浏览网页，或通过分享/粘贴链接识别可缓存视频，支持整部剧集一键批量下载与本地播放。各端片库默认独立；局域网可将已缓存内容投送到 Android TV 大屏播放。

> **一句话**：嗅探 / 解析 → 缓存到本机 → 本地播放；TV 可从局域网设备接收成片。

## 特性（规划）

- **发现与嗅探**：内置 WebView 浏览，自动列出页面中的媒体候选
- **多种入口**：粘贴 URL；Android / iOS 系统「分享到本 App」
- **通用解析**：直链 MP4、HLS / m3u8；识别分集列表时支持勾选与一键缓存整剧
- **下载队列**：并发控制、暂停 / 继续、失败重试、断点续传
- **本地片库**：单片与剧集分模型管理，支持进度与倍速（本机保存）
- **局域网投送**：手机 / 电脑 → Android TV，设备发现、可选 PIN 配对、传输文件与元数据

## 技术栈

| 层级 | 选型 |
|------|------|
| UI | Flutter（含 Android TV 焦点布局） |
| 引擎 | Rust（嗅探、解析、下载、片库、局域网） |
| 桥接 | FFI（flutter_rust_bridge 等） |
| 播放 | media_kit 或等价方案 |
| 数据库 | SQLite（经 Rust 引擎） |
| 局域网 | mDNS + TLS 文件传输 |

## 项目结构（目标）

```
video_sniffing/
├── engine/          # Rust：嗅探解析、下载、剧集、媒体库、LAN
├── app/             # Flutter：多端 UI + 平台通道
└── platforms/       # 少量原生胶水（iOS Share Extension、WebView 钩子等）
```

## 当前状态

项目处于**设计与引擎搭建初期**，尚未提供可安装的应用包。实现将按子系统分阶段推进：引擎核心与片库 → 下载器 → 解析与嗅探 → Flutter 壳层 → 平台胶水 → 局域网投送。

## 原则与声明

- **工具定位**：用户对自己有权离线使用的内容负责；本项目不提供侵权片源导航或站点破解插件市场。
- **开源可审计**：引擎与客户端均可自行编译、审查与修改。
- **一期不做**：音乐、账号与云同步、智能追更、系统级 VPN / 代理抓包、内置站点目录。
